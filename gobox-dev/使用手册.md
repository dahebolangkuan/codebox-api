## 1. 项目概述

GoBox 是一个高性能的沙箱代码执行编排器，专为 LLM 应用设计。它提供安全、隔离的环境来运行 Python 和 Bash 代码。

### 核心特性

| 特性 | 描述 |
|------|------|
| **高并发** | 利用 Go 的 goroutines 支持数千个并发会话 |
| **容器池** | 预热容器池，毫秒级响应时间 |
| **云原生** | 原生支持 Docker 和 Kubernetes 编排 |
| **单一二进制** | 无依赖，跨平台部署 |
| **流式执行** | 通过 JSONL/SSE 实时输出流 |
| **多驱动** | 支持 Docker（本地）、Remote（API）、Kubernetes（规划中） |

### 支持的执行内核

- **Python**: 完整的 Python 执行环境
- **Bash**: Shell 命令执行

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                          用户代码                                │
│   sandbox := gobox.New(gobox.WithDriver("docker"))              │
│   result, _ := sandbox.Exec(ctx, "print('Hello')")              │
└─────────────────────────────────────────────────────────────────┘
                                 │
                                 ▼
┌─────────────────────────────────────────────────────────────────┐
│                     GoBox Core (pkg/gobox)                       │
│   Sandbox Interface, Types, Errors, Options                      │
└─────────────────────────────────────────────────────────────────┘
                                 │
          ┌──────────────────────┼──────────────────────┐
          ▼                      ▼                      ▼
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│  DockerDriver   │   │  RemoteDriver   │   │   K8sDriver     │
│  (pkg/docker)   │   │  (pkg/remote)   │   │   (pkg/k8s)     │
│                 │   │                 │   │                 │
│  Container Pool │   │  HTTP Client    │   │  Pod Manager    │
│  Docker SDK     │   │  JSONL/SSE      │   │  client-go      │
└─────────────────┘   └─────────────────┘   └─────────────────┘
```

### 核心组件

| 组件 | 路径 | 功能 |
|------|------|------|
| `gobox` CLI | `cmd/gobox/` | 命令行工具 |
| `gobox-server` | `cmd/gobox-server/` | HTTP API 服务 |
| `pkg/gobox` | 核心接口定义 | Sandbox 接口、类型、选项 |
| `pkg/docker` | Docker 驱动 | 容器创建、管理、代码执行 |
| `pkg/remote` | 远程驱动 | HTTP 客户端连接远程服务 |
| `pkg/server` | HTTP 服务 | RESTful API 服务实现 |
| `pkg/config` | 配置管理 | 环境变量、配置文件加载 |

## 3. 环境准备

### 3.1 系统要求

- **Go**: >= 1.22
- **Docker**: >= 20.10（用于 Docker 驱动）
- **操作系统**: Linux, macOS, Windows

### 3.2 安装 Go

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install -y golang-go

# macOS
brew install go
```

### 3.3 安装 Docker

```bash
# Ubuntu
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER

# macOS
brew install --cask docker

# 验证安装
docker --version
docker run hello-world
```

### 3.4 克隆项目

```bash
cd /path/to/workspace
# 项目已在 gobox-dev/gobox 目录下
```

## 4. 编译构建

### 4.1 使用 Makefile 构建（推荐）

```bash
# 进入项目目录
cd gobox-dev/gobox

# 查看所有可用命令
make help

# 下载依赖
make deps

# 构建所有二进制文件
make build

# 只构建 CLI
make build-cli

# 只构建 Server
make build-server
```

### 4.2 构建输出

构建完成后，二进制文件位于 `bin/` 目录：

```
bin/
├── gobox           # CLI 工具
└── gobox-server    # HTTP API 服务
```

### 4.3 手动构建

```bash
# 构建 CLI
go build -o bin/gobox ./cmd/gobox

# 构建 Server
go build -o bin/gobox-server ./cmd/gobox-server

# 带版本信息的构建
VERSION=$(git describe --tags --always --dirty 2>/dev/null || echo "dev")
BUILD_TIME=$(date -u '+%Y-%m-%d_%H:%M:%S')
go build -ldflags "-X main.version=$VERSION -X main.buildTime=$BUILD_TIME" \
    -o bin/gobox ./cmd/gobox
```

### 4.4 跨平台编译

```bash
# 一键构建所有平台
make release

# 或手动指定平台
GOOS=linux GOARCH=amd64 go build -o bin/gobox-linux-amd64 ./cmd/gobox
GOOS=darwin GOARCH=arm64 go build -o bin/gobox-darwin-arm64 ./cmd/gobox
GOOS=windows GOARCH=amd64 go build -o bin/gobox-windows-amd64.exe ./cmd/gobox
```

### 4.5 安装到系统

```bash
# 安装到 GOPATH/bin
make install

# 或手动安装
sudo cp bin/gobox /usr/local/bin/
sudo cp bin/gobox-server /usr/local/bin/
```

## 5. Docker 镜像准备

### 5.1 使用官方镜像（推荐）

GoBox 默认使用 `shroominic/codebox:latest` 镜像：

```bash

docker pull shroominic/codebox:latest
```

### 5.2 构建自定义执行器镜像

项目提供了 Dockerfile.executor 用于自定义执行环境：

```bash
# 构建执行器镜像
cd docker/
docker build -f Dockerfile.executor -t my-executor:latest .
```

Dockerfile.executor 内容说明：

```dockerfile
# 基于 Python 3.11
FROM python:3.11-slim

# 安装常用 Python 包
RUN pip install --no-cache-dir \
    numpy pandas matplotlib pillow requests jupyter ipykernel

# 创建非 root 用户（安全）
RUN useradd -m -s /bin/bash executor
USER executor

# 设置环境变量
ENV PYTHONUNBUFFERED=1
ENV MPLBACKEND=Agg  # matplotlib 非交互后端
```

### 5.3 构建 GoBox Server 镜像

```bash
# 构建 server 镜像
make docker

# 或手动构建
docker build -t gobox:latest -f docker/Dockerfile .
```

## 7. Server 使用方式

### 7.1 启动服务

```bash
# 默认配置启动（端口 8069）
./bin/gobox-server

# 指定端口
./bin/gobox-server --port 8080

# 完整配置启动
./bin/gobox-server \
    --port 8080 \
    --host 0.0.0.0 \
    --driver docker \
    --image shroominic/codebox:latest \
    --pool-min 2 \
    --pool-max 10 \
    --timeout 60 \
    --memory 536870912 \
    --cpu-quota 100000
```

### 7.2 启用认证

```bash
# 启用 Token 认证
./bin/gobox-server --auth --auth-token YOUR_SECRET_TOKEN
```

### 7.3 使用 Docker 运行 Server

```bash
# 运行 server 容器（需要访问 Docker socket）
docker run -d \
    --name gobox-server \
    -p 8069:8069 \
    -v /var/run/docker.sock:/var/run/docker.sock \
    gobox:latest

# 查看日志
docker logs -f gobox-server
```

### 7.4 Server 配置选项

| 选项 | 默认值 | 描述 |
|------|--------|------|
| `--port` | 8069 | 服务端口 |
| `--host` | 0.0.0.0 | 绑定地址 |
| `--driver` | docker | 沙箱驱动 |
| `--image` | shroominic/codebox:latest | Docker 镜像 |
| `--pool-min` | 2 | 最小容器池大小 |
| `--pool-max` | 10 | 最大容器池大小 |
| `--timeout` | 60 | 默认执行超时（秒） |
| `--memory` | 512MB | 内存限制（字节） |
| `--cpu-quota` | 100000 | CPU 配额 |
| `--auth` | false | 启用认证 |
| `--auth-token` | - | 认证 Token |
| `--cors` | true | 启用 CORS |

## 8. Go SDK 编程使用

### 8.1 基本使用

```go
package main

import (
    "context"
    "fmt"
    "log"
    "time"

    "gobox/pkg/docker"
    "gobox/pkg/gobox"
)

func main() {
    // 创建 Docker 沙箱
    sandbox, err := docker.New(
        docker.WithImage("shroominic/codebox:latest"),
        docker.WithTimeout(60*time.Second),
        docker.WithPoolSize(1, 5),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer sandbox.Close()

    // 创建带超时的 context
    ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()

    // 执行代码
    result, err := sandbox.Exec(ctx, `print("Hello, GoBox!")`)
    if err != nil {
        log.Fatal(err)
    }

    fmt.Println(result.Text()) // 输出: Hello, GoBox!
}
```

### 8.2 使用工厂模式创建

```go
import "gobox/pkg/gobox"

// 使用统一接口创建沙箱
sandbox, err := gobox.New(
    gobox.WithDriver("docker"),
    gobox.WithImage("shroominic/codebox:latest"),
    gobox.WithDefaultTimeout(60*time.Second),
    gobox.WithMemory(512*1024*1024),
    gobox.WithCPUQuota(100000),
)
if err != nil {
    log.Fatal(err)
}
defer sandbox.Close()
```

### 8.3 流式输出

```go
// 流式执行代码
chunkChan, errChan := sandbox.StreamExec(ctx, `
import time
for i in range(5):
    print(f"Step {i+1}/5")
    time.sleep(1)
`)

// 处理流式输出
for {
    select {
    case chunk, ok := <-chunkChan:
        if !ok {
            // 检查错误
            select {
            case err := <-errChan:
                if err != nil {
                    log.Fatal(err)
                }
            default:
            }
            return
        }
        
        switch chunk.Type {
        case gobox.ChunkTypeText:
            fmt.Print(chunk.Content)
        case gobox.ChunkTypeError:
            fmt.Fprintf(os.Stderr, "Error: %s", chunk.Content)
        case gobox.ChunkTypeImage:
            fmt.Printf("[Image: %d bytes]\n", len(chunk.Content))
        }
        
    case err := <-errChan:
        if err != nil {
            log.Fatal(err)
        }
        return
    }
}
```

### 8.4 文件操作

```go
import (
    "strings"
    "io"
)

// 上传文件
file := gobox.File{
    Name:    "data.csv",

}

// 下载文件

    log.Fatal(err)
}

content, _ := io.ReadAll(reader)

```

### 8.5 安装包

```go
// 安装 Python 包
if err := sandbox.Install(ctx, "numpy", "pandas", "matplotlib"); err != nil {
    log.Fatal(err)
}

// 使用安装的包
result, err := sandbox.Exec(ctx, `

```

### 8.6 执行选项

```go
// 设置执行选项
result, err := sandbox.Exec(ctx, "echo $MY_VAR",
    gobox.WithKernel("bash"),           // 使用 bash 内核
    gobox.WithTimeout(30*time.Second),  // 执行超时
    gobox.WithCwd("/tmp"),              // 工作目录
    gobox.WithEnv(map[string]string{    // 环境变量
        "MY_VAR": "hello",
    }),
)
```

### 8.7 错误处理

```go
result, err := sandbox.Exec(ctx, "x = 1/0")
if err != nil {
    // 执行错误
    log.Printf("Execution error: %v", err)
    return
}

// 检查运行时错误
if result.HasError() {
    for _, errMsg := range result.Errors() {
        log.Printf("Runtime error: %s", errMsg)
    }
}

// 获取输出
fmt.Println("Output:", result.Text())
fmt.Println("Images:", len(result.Images()))
```

### 9.6 Python 客户端示例

```python
import requests
import json

BASE_URL = "http://localhost:8069"

# 执行代码
def exec_code(code, kernel="python"):
    response = requests.post(
        f"{BASE_URL}/exec",
        json={"code": code, "kernel": kernel},
        stream=True
    )
    
    for line in response.iter_lines():
        if line:
            chunk = json.loads(line)
            if chunk["type"] == "txt":
                print(chunk["content"], end="")
            elif chunk["type"] == "err":
                print(f"Error: {chunk['content']}")

# 使用示例
exec_code("print('Hello from Python!')")
exec_code("echo 'Hello from Bash!'", kernel="bash")
```

## 12. 故障排除

### 12.1 常见问题

#### Docker 连接失败

```bash
# 检查 Docker 是否运行
docker info

# 检查 Docker socket 权限
ls -la /var/run/docker.sock

# 将用户加入 docker 组
sudo usermod -aG docker $USER
# 重新登录生效
```

#### 镜像拉取失败

```bash
# 手动拉取镜像
docker pull shroominic/codebox:latest

# 使用国内镜像源
# 编辑 /etc/docker/daemon.json
{
    "registry-mirrors": ["https://mirror.ccs.tencentyun.com"]
}
sudo systemctl restart docker
```

#### 执行超时

```bash
# 增加超时时间
./bin/gobox -t 300 exec "long_running_code()"

# 或在代码中设置
gobox.WithTimeout(5 * time.Minute)
```

#### 内存不足

```bash
# 增加内存限制
./bin/gobox-server --memory 1073741824  # 1GB
```

### 12.2 调试模式

```bash
# 启用详细日志
GOBOX_LOG_LEVEL=debug ./bin/gobox-server

# CLI 详细模式
./bin/gobox -v exec "print('debug')"
```

### 12.3 运行测试

