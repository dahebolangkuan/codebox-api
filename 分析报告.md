## 1. 项目概述

### 1.1 项目定位

CodeBox API 是一个为 LLM (大语言模型) 应用和服务提供云基础设施的 Python 库。它允许用户在隔离/沙箱环境中运行 Python 代码，主要用于：

- **代码解释器功能**: 为 AI Agent 提供安全的代码执行环境
- **沙箱隔离**: 确保执行的代码不会影响主机系统
- **多租户支持**: 支持并行执行多个独立会话

### 1.2 技术栈

| 组件 | 技术选型 |
|------|----------|
| 核心语言 | Python 3.9+ |
| HTTP 客户端 | httpx (同步/异步) |
| 异步运行时 | anyio |
| 本地执行 | IPython InteractiveShell |
| API 服务 | FastAPI + Uvicorn |
| 容器化 | Docker |
| 重试机制 | tenacity |
| 构建系统 | hatchling |
| 包管理 | rye/uv |

### 1.3 项目结构

```
codebox-api/
├── src/codeboxapi/        # 核心源代码
│   ├── __init__.py        # 公开 API 导出
│   ├── codebox.py         # 核心 CodeBox 抽象基类
│   ├── local.py           # 本地执行实现 (LocalBox)
│   ├── remote.py          # 远程 API 客户端 (RemoteBox)
│   ├── docker.py          # Docker 容器实现 (DockerBox)
│   ├── api.py             # FastAPI 服务端
│   ├── types.py           # 数据类型定义
```

## 3. 核心模块详解

### 3.1 CodeBox 基类 (`codebox.py`)

#### 核心职责

1. **工厂模式**: 通过 `__new__` 方法实现实例类型的动态选择
2. **接口定义**: 定义所有实现类必须实现的抽象方法
3. **便捷方法**: 提供同步/异步的辅助方法

#### 关键代码分析

```python
class CodeBox:
    def __new__(cls, *args, **kwargs) -> "CodeBox":
        api_key = kwargs.get("api_key") or os.getenv("CODEBOX_API_KEY")
        
        if api_key == "local":
            return import_module("codeboxapi.local").LocalBox(*args, **kwargs)
        if api_key == "docker":
            return import_module("codeboxapi.docker").DockerBox(*args, **kwargs)
        return import_module("codeboxapi.remote").RemoteBox(*args, **kwargs)
```

**设计亮点**:
- 延迟导入 (`import_module`) 避免循环依赖和不必要的模块加载
- 透明的实现切换，用户代码无需修改

#### 方法分类

| 类型 | 同步方法 | 异步方法 | 说明 |
|------|----------|----------|------|
| 执行 | `exec()` | `aexec()` | 执行代码 |
| 流式执行 | `stream_exec()` | `astream_exec()` | 流式执行代码 |
| 文件上传 | `upload()` | `aupload()` | 上传文件 |
| 文件下载 | `download()` | `adownload()` | 下载文件 |
| 流式下载 | `stream_download()` | `astream_download()` | 流式下载 |
| 健康检查 | `healthcheck()` | `ahealthcheck()` | 检查实例状态 |
| 包安装 | `install()` | `ainstall()` | 安装 Python 包 |
| 文件列表 | `list_files()` | `alist_files()` | 列出文件 |
| 包列表 | `list_packages()` | `alist_packages()` | 列出已安装包 |
| 变量查看 | `show_variables()` | `ashow_variables()` | 查看变量 |
| 重启 | `restart()` | `arestart()` | 重启内核 |
| 保活 | `keep_alive()` | `akeep_alive()` | 保持会话 |

### 3.2 LocalBox 实现 (`local.py`)

#### 核心特性

1. **单例模式**: 确保只有一个 LocalBox 实例存在
2. **IPython 集成**: 使用 `InteractiveShell` 执行 Python 代码
3. **Matplotlib 补丁**: 重写 `plt.show()` 捕获图像输出
4. **多线程流式输出**: 使用队列实现流式执行结果

#### 关键实现细节

**单例控制**:
```python
class LocalBox(CodeBox):
    _instance: t.Optional["LocalBox"] = None

    def __new__(cls, *args, **kwargs) -> "LocalBox":
        if cls._instance:
            raise RuntimeError("Only one LocalBox instance can exist at a time.")
        instance = object.__new__(cls)
        cls._instance = instance
        return instance
```

**Matplotlib 图像捕获**:
```python
def _patch_matplotlib_show(self) -> None:
    import matplotlib.pyplot as plt
    
    def custom_show(close=True):
        fig = plt.gcf()
        buf = io.BytesIO()
        fig.savefig(buf, format="png")
        buf.seek(0)
        img_str = base64.b64encode(buf.getvalue()).decode("utf-8")
        important_print(f"<image>{img_str}</image>")
        if close:
            plt.close(fig)
    
    plt.show = custom_show
```

**流式执行架构**:
```
┌─────────────────────────────────────────────────────────────┐
│                    stream_exec 执行流程                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐   │
│  │  run_cell   │────▶│   Queue     │◀────│  stream     │   │
│  │  Thread     │     │             │     │  Thread     │   │
│  └─────────────┘     └─────────────┘     └─────────────┘   │
│        │                   │                   │           │
│        ▼                   ▼                   ▼           │
│  执行 IPython       存储 ExecChunk        捕获 stdout     │
│     代码                                   stderr         │
│                                                             │
│  主线程: while True → queue.get() → yield chunk           │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 RemoteBox 实现 (`remote.py`)

#### 核心特性

1. **HTTP 客户端**: 使用 httpx 进行同步/异步请求
2. **重试机制**: 使用 tenacity 处理 502 错误
3. **流式响应**: 支持 SSE 风格的流式代码执行

#### 关键实现

**重试装饰器**:
```python
@retry(
    retry=retry_if_exception(
        lambda e: isinstance(e, httpx.HTTPStatusError)
        and e.response.status_code == 502
    ),
    wait=wait_exponential(multiplier=1, min=5, max=150),
    stop=stop_after_attempt(3),
)
```

**流式解析协议**:
```python
# 服务端发送: <txt>内容</txt><img>base64</img><err>错误</err>
async for chunk in response.aiter_text():
    buffer += chunk
    while match := re.match(r"<(txt|img|err)>(.*?)</\1>", buffer, re.DOTALL):
        _, end = match.span()
        t, c = match.groups()
        yield ExecChunk(type=t, content=c)
        buffer = buffer[end:]
```

### 3.4 DockerBox 实现 (`docker.py`)

#### 核心特性

1. **继承 RemoteBox**: 复用所有 HTTP 通信逻辑
2. **自动容器管理**: 自动启动和配置 Docker 容器
3. **端口管理**: 智能分配可用端口支持并行实例

#### 初始化流程

```python
def __init__(self, port_or_range=(8069,), image="shroominic/codebox:latest", ...):
    self.port = get_free_port(port_or_range)
    subprocess.run([
        "docker", "run", "-d", "--rm",
        "-e", f"CODEBOX_TIMEOUT={timeout}",
        "-p", f"{self.port}:8069",
        image,
    ])
    self._wait_for_startup()  # 等待容器就绪
```

## 5. 设计模式应用

### 5.1 工厂模式 (Factory Pattern)

**应用位置**: `CodeBox.__new__`

```python
def __new__(cls, *args, **kwargs) -> "CodeBox":
    api_key = kwargs.get("api_key") or os.getenv("CODEBOX_API_KEY")
    if api_key == "local":
        return LocalBox(...)
    if api_key == "docker":
        return DockerBox(...)
    return RemoteBox(...)
```

**优点**:
- 用户代码与具体实现解耦
- 可以通过环境变量切换实现
- 扩展新的实现类只需修改工厂方法

### 5.2 单例模式 (Singleton Pattern)

**应用位置**: `LocalBox._instance`

**优点**:
- 防止资源冲突 (IPython Shell 是全局的)
- 明确告知用户并行执行的限制

**局限**:
- 不支持真正的单进程并行测试
- 需要用户手动管理实例生命周期

### 5.3 模板方法模式 (Template Method Pattern)

**应用位置**: `CodeBox` 基类定义流程，子类实现具体步骤

```python
# 基类定义流程
def exec(self, code, ...):
    return flatten_exec_result(self.stream_exec(code, ...))

# 子类实现具体步骤
def stream_exec(self, code, ...):  # LocalBox/RemoteBox 各自实现
    ...
```

### 5.4 装饰器模式 (Decorator Pattern)

**应用位置**: 
- `@deprecated` 标记废弃方法
- `@retry` tenacity 重试装饰器

### 5.5 依赖注入 (Dependency Injection)

**应用位置**: FastAPI 的 `Depends(get_codebox)`

```python
@app.post("/exec")
async def exec(
    exec: ExecBody, 
    codebox: LocalBox = Depends(get_codebox)  # 注入 codebox 实例
)
```

### 5.6 延迟加载 (Lazy Loading)

**应用位置**: `RemoteFile` 的内容和大小

```python
def get_content(self) -> bytes:
    if self._content is None:  # 首次访问时才加载
        self._content = b"".join(self.remote.stream_download(self.path))
    return self._content
```

## 6. 优化空间与建议

### 6.1 架构层面优化

#### 6.1.1 缺少统一的抽象基类

**现状**: `CodeBox` 同时承担工厂和抽象基类的角色，但没有使用 `abc.ABC`

**建议**:
```python
from abc import ABC, abstractmethod

class BaseBox(ABC):
    """抽象基类，定义接口规范"""
    
    @abstractmethod
    def stream_exec(self, code, kernel, timeout, cwd) -> Generator[ExecChunk, None, None]:
        pass
    
    @abstractmethod
    def upload(self, remote_file_path, content, timeout) -> RemoteFile:
        pass
    
    # ... 其他抽象方法

class CodeBox(BaseBox):
    """工厂类 + 提供便捷方法的混入"""
    
    def __new__(cls, *args, **kwargs):
        # 工厂逻辑
        ...
```

#### 6.1.2 LocalBox 单例限制过强

**现状**: 整个进程只能有一个 LocalBox 实例

**建议**: 使用事件驱动或条件变量
```python
import queue

def stream_exec(self, code, ...):
    output_queue = queue.Queue()
    result_event = threading.Event()
    
    def _run_cell():
        # 执行代码，将输出放入队列
        result_event.set()
    
    while not result_event.is_set() or not output_queue.empty():
        try:
            chunk = output_queue.get(timeout=0.1)
            yield chunk
        except queue.Empty:
            continue
```

```python
        def wrapper(*args, **kwargs):
            warnings.warn(

                + (f" Will be removed in version {removal_version}." if removal_version else ""),

                stacklevel=2

    return decorator
```

```python
def _safe_path(self, remote_path: str) -> str:
    # 规范化路径，防止路径遍历攻击
    safe_path = os.path.normpath(remote_path)
    if safe_path.startswith("..") or os.path.isabs(safe_path):
        raise ValueError("Invalid file path")
    full_path = os.path.join(self.cwd, safe_path)
    if not full_path.startswith(os.path.abspath(self.cwd)):
        raise ValueError("Path traversal detected")
    return full_path
```
